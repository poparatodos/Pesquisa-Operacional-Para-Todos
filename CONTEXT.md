# Pesquisa Operacional Para Todos

Site do projeto de extensão da UNIRIO que disponibiliza videoaulas e materiais de Pesquisa Operacional de forma aberta e gratuita.

## Language

**Disciplina**:
Uma trilha de conteúdo do site (PO I, PO II, Problemas Clássicos), composta por uma sequência de aulas.
_Avoid_: curso, matéria, cadeira

**Aula**:
Uma unidade de conteúdo dentro de uma disciplina, com título, descrição, tópicos, uma ou mais partes de vídeo e materiais de apoio.
_Avoid_: vídeo (uma aula pode ter várias partes), módulo, lição

**Parte**:
Um vídeo individual de uma aula quando ela é dividida (ex.: "SOLVER pt. 1", "SOLVER pt. 2").
_Avoid_: subvídeo, clipe, capítulo

**Material**:
Um arquivo de apoio de uma aula, disponibilizado para download (tipicamente slides `.pptx`/`.ppt`).
_Avoid_: anexo, slide (um slide é uma página do arquivo), documento

**Problema Clássico**:
Um problema conhecido da Pesquisa Operacional explicado no site; é modelado como uma Disciplina para reaproveitar o mesmo formato de aulas.
_Avoid_: exemplo, exercício, caso
